# Настройка авторизации через ВКонтакте (VK ID)

## 📋 Предварительные требования

Для работы авторизации через ВКонтакте необходимо:
1. Зарегистрированное приложение ВКонтакте (Mini App)
2. Сервисный ключ доступа (Service Key)
3. Правильно настроенные Redirect URI

---

## 🔧 Шаг 1: Создание приложения ВКонтакте

1. Перейдите в [VK Developers](https://dev.vk.com/)
2. Войдите под своим аккаунтом VK
3. Нажмите **"Мои приложения"** → **"Создать"**
4. Выберите тип приложения: **"Mini App"**
5. Заполните информацию:
   - **Название:** Yoga Studio CRM (или ваше название)
   - **Описание:** Система управления йога-студией
   - **Сайт:** https://your-domain.com (ваш домен)
   - **Base URL:** https://your-domain.com/
6. После создания вы получите:
   - **App ID** (например, `54601779`)
   - **Secure Key** (Сервисный ключ доступа)

---

## 🔐 Шаг 2: Настройка OAuth

1. В панели управления приложением перейдите в раздел **"Настройки"** → **"OAuth"**
2. В разделе **"Redirect URI"** добавьте следующие URI:

```
https://your-domain.com/api/auth/vk/
http://localhost:8000/api/auth/vk/
http://127.0.0.1:8000/api/auth/vk/
```

⚠️ **Важно:** Добавьте ВСЕ варианты доменов, которые будете использовать (production + local development)

3. Убедитесь, что включены следующие права доступа (scopes):
   - `email` — доступ к email пользователя
   - `userinfo` — доступ к информации о пользователе

4. Сохраните настройки

---

## 📝 Шаг 3: Настройка .env файла

Добавьте в файл `.env` следующие переменные:

```bash
# VK ID Authentication
VK_CLIENT_ID=54601779                    # Ваш App ID из шага 1
VK_SERVICE_KEY=xxxxxxxxxxxxxxxxxxxxxxxx  # Сервисный ключ доступа из шага 1
```

⚠️ **Важно:** 
- `VK_CLIENT_ID` — это числовой идентификатор приложения (App ID)
- `VK_SERVICE_KEY` — это строка символов (Secure Key)

---

## 💻 Шаг 4: Обновление кода

После настройки `.env` файла код автоматически подхватит `VK_CLIENT_ID` через шаблон Django.

### Проверка настроек в Django

Убедитесь, что в `yoga_crm/settings.py` есть:

```python
VK_SERVICE_KEY = config('VK_SERVICE_KEY', default='')
VK_CLIENT_ID = config('VK_CLIENT_ID', default='')
```

Эти настройки уже присутствуют в проекте.

---

## 🧪 Шаг 5: Тестирование

1. Запустите сервер разработки:
   ```bash
   python manage.py runserver
   ```

2. Откройте страницу входа: `http://127.0.0.1:8000/login/`

3. Нажмите кнопку **"Войти через ВКонтакте"**

4. Ожидаемое поведение:
   - Открывается всплывающее окно VK ID
   - Вы подтверждаете вход
   - Окно закрывается
   - Происходит перенаправление в личный кабинет (`/profile/`)

## 🛠 Возможные проблемы и решения

### Проблема 1: Редирект на vk.com/id вместо авторизации

**Причина:** Неправильно настроен Redirect URI в приложении VK

**Решение:**
1. Проверьте, что в настройках приложения добавлен точный URL: `http://127.0.0.1:8000/api/auth/vk/`
2. Убедитесь, что protocol (http/https) совпадает
3. Перезагрузите страницу входа (Ctrl+Shift+R)

### Проблема 2: Ошибка "VK авторизация не настроена"

**Причина:** Не указан `VK_SERVICE_KEY` в `.env`

**Решение:**
1. Проверьте, что файл `.env` существует
2. Убедитесь, что `VK_SERVICE_KEY` скопирован без лишних пробелов
3. Перезапустите Django сервер

### Проблема 3: VK SDK не загружается

**Причина:** Блокировщики рекламы или CORS политика

**Решение:**
1. Отключите блокировщики рекламы для localhost
2. Проверьте консоль браузера (F12) на наличие ошибок
3. Убедитесь, что у вас есть подключение к интернету

### Проблема 4: Ошибка "Invalid request" от VK API

**Причина:** Неправильный сервисный ключ или истёкший access token

**Решение:**
1. Проверьте правильность `VK_SERVICE_KEY`
2. Убедитесь, что приложение не заблокировано
3. Попробуйте пересоздать сервисный ключ в настройках приложения

## 🔒 Безопасность

- Никогда не коммитьте файл `.env` в репозиторий
- Используйте разные приложения для development и production
- Регулярно обновляйте сервисные ключи
- Включите HTTPS в production
