# Yoga CRM - Система управления для преподавателя йоги

## Описание
Простая CRM-система для ведения учета посещаемости, оплат занятий и оплаты аренды залов..

## Функционал
- **Клиенты**: учет учеников (имя, фамилия, телефон, email)
- **Залы**: управление залами для аренды (название, адрес, цена за час)
- **Занятия**: расписание занятий (название, дата/время, длительность, зал, инструктор)
- **Посещаемость**: отметка о посещении занятий клиентами
- **Оплаты занятий**: учет оплат от клиентов (разовые, абонементы, пакеты)
- **Оплаты аренды**: учет расходов на аренду залов

## Установка и запуск

### 1. Установка зависимостей
```bash
pip install django psycopg2-binary
```

### 2. Применение миграций
```bash
python manage.py migrate
```

### 3. Создание суперпользователя (если нужно)
```bash
python manage.py createsuperuser
```

### 4. Запуск сервера
```bash
python manage.py runserver
```

### 5. Доступ к админ-панели
Откройте в браузере: http://127.0.0.1:8000/admin/

**Логин по умолчанию**: `admin`  
**Пароль по умолчанию**: `admin123`

## Структура базы данных

### Модели:
1. **Client** - Клиент (ученик)
2. **Hall** - Зал для аренды
3. **ClassSession** - Занятие
4. **Attendance** - Посещаемость
5. **Payment** - Оплата занятий
6. **RentPayment** - Оплата аренды

## Настройка PostgreSQL (опционально)

Для использования PostgreSQL вместо SQLite:

1. Установите PostgreSQL и создайте базу данных:
```sql
CREATE DATABASE yoga_crm;
CREATE USER yoga_user WITH PASSWORD 'your_password';
GRANT ALL PRIVILEGES ON DATABASE yoga_crm TO yoga_user;
```

2. Обновите настройки в `yoga_crm/settings.py`:
```python
DATABASES = {
    'default': {
        'ENGINE': 'django.db.backends.postgresql',
        'NAME': 'yoga_crm',
        'USER': 'yoga_user',
        'PASSWORD': 'your_password',
        'HOST': 'localhost',
        'PORT': '5432',
    }
}
```
