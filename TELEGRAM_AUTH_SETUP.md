# Настройка авторизации через Telegram

## Инструкция по настройке

### 1. Создание Telegram бота

1. Откройте Telegram и найдите бота **@BotFather**
2. Отправьте команду `/newbot`
3. Введите имя бота (например: `Yoga CRM Auth`)
4. Введите username бота (должен заканчиваться на `bot`, например: `yoga_crm_auth_bot`)
5. Сохраните полученный токен (выглядит как: `1234567890:ABCdefGHIjklMNOpqrsTUVwxyz`)

### 2. Настройка домена для виджета

1. В @BotFather отправьте команду `/setdomain`
2. Выберите вашего бота
3. Введите домен вашего сайта (для локальной разработки можно использовать ngrok или другой туннель)

**Важно:** Для локальной разработки Telegram требует HTTPS. Используйте:
- [ngrok](https://ngrok.com/) - `ngrok http 8000`
- [localtunnel](https://theboroer.github.io/localtunnel-www/) 
- Или разверните на сервере с HTTPS

### 3. Настройка проекта

#### Файл `.env`

Заполните файл `.env` своими данными:

```bash
# Токен вашего бота из @BotFather
TELEGRAM_BOT_TOKEN=1234567890:ABCdefGHIjklMNOpqrsTUVwxyz

# Секретный ключ Django (для production используйте свой)
DJANGO_SECRET_KEY=your-secret-key-here
```

#### Файл `login.html`

Откройте файл `core/templates/core/login.html` и замените `YOUR_BOT_USERNAME` на username вашего бота (без @):

```javascript
script.setAttribute('data-telegram-login', 'yoga_crm_auth_bot'); // Ваш username бота
```

### 4. Применение миграций

```bash
python manage.py migrate
```

### 5. Запуск сервера

```bash
python manage.py runserver
```

## Как это работает

1. Пользователь нажимает кнопку "Войти через Telegram"
2. Telegram запрашивает подтверждение доступа к данным
3. После подтверждения Telegram передаёт данные пользователя (id, имя, username)
4. Сервер проверяет криптографическую подпись данных
5. Если пользователь с таким `telegram_id` существует — выполняется вход
6. Если пользователя нет — создаётся новый аккаунт автоматически

## Регистрация происходит при первой авторизации

- **Первый вход**: Создаётся новый пользователь с `telegram_id`, выполняется автоматический вход
- **Повторный вход**: Пользователь находится по `telegram_id`, выполняется вход без регистрации

## Безопасность

- Данные от Telegram проверяются через HMAC-SHA256 подпись
- Токен бота хранится в `.env` файле (не публикуется в Git)
- Данные авторизации действительны 24 часа
- Используется CSRF защита Django

## Уведомления и рассылки

После авторизации у вас есть `telegram_id` пользователя, что позволяет:

1. **Отправлять уведомления о записях** — напоминания о предстоящих занятиях
2. **Рассылать акции** — специальные предложения для клиентов
3. **Уведомлять об изменениях** — отмены занятий, переносы времени

Для отправки сообщений используйте Telegram Bot API:

```python
import requests

def send_telegram_message(telegram_id, message, bot_token):
    url = f"https://api.telegram.org/bot{bot_token}/sendMessage"
    data = {
        'chat_id': telegram_id,
        'text': message
    }
    response = requests.post(url, json=data)
    return response.json()
```

**Важно:** Пользователь должен начать диалог с ботом (нажать Start), чтобы вы могли отправлять сообщения.

## Troubleshooting

### Ошибка "Telegram бот не настроен"
- Проверьте, что `TELEGRAM_BOT_TOKEN` указан в `.env`
- Перезапустите сервер после изменения `.env`

### Виджет не отображается
- Проверьте, что username бота указан без символа `@`
- Убедитесь, что домен настроен в @BotFather через `/setdomain`
- Для localhost используйте HTTPS туннель (ngrok)

### Ошибка авторизации
- Проверьте, что токен бота верный
- Убедитесь, что время на сервере синхронизировано
- Данные авторизации действительны только 24 часа
