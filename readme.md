# Django CRM для йога-студии

**Статус:** Активная разработка
**Стек:** Django (Python), SQLite, HTML/CSS, Vanilla JS, FullCalendar.js v6

---

## 📋 Описание проекта

CRM-система для управления йога-студией с полным циклом: от расписания занятий и управления залами до учёта посещаемости, финансов и личного кабинета ученика.

### ✅ Реализованный функционал

#### Модели данных (`core/models.py`)
| Модель | Описание |
|--------|----------|
| `Tariff` | **Новая модель**: Тарифы для занятий (групповые, индивидуальные, сплит). Поля: название, тип тарифа, цена за человека, полная цена за сплит, макс. участников, описание, статус активности |
| `User` | Пользователи и клиенты студии в одной модели (наследуется от `AbstractUser`). Поля: username (логин), телефон, имя, фамилия, роль (ученик/модератор/администратор), статус активности, баланс, остаток абонемента, **allowed_tariffs** (M2M связь с тарифами) |
| `Hall` | Залы с полем `color` (10 цветовых вариантов) |
| `ClassType` | Типы занятий (название, описание, длительность, **default_tariff**) |
| `ClassSession` | Расписание занятий с поддержкой повторяющихся событий. **Добавлено поле tariff** (связь с тарифом), удалено поле max_participants |
| `Booking` | **Новая модель**: Записи пользователей на занятия. Поля: сессия, клиент, статус (pending/confirmed/paid/cancelled), дата записи, дедлайн оплаты (за 4 часа), дата оплаты, сумма оплаты |
| `PaymentTransaction` | **Новая модель**: Детализированная история финансовых операций. Поля: клиент, тип операции (deposit/debit/refund/adjustment), сумма, баланс до/после, связь с записью |
| `Attendance` | Посещаемость (клиент + занятие + статус) - используется для статистики после занятия |
| `Payment` | Оплата клиентами (разовое/абонемент/пакет) - для прямого пополнения баланса |
| `RentPayment` | Оплата аренды залов |

#### Ключевые особенности
- **Повторяющиеся события:** При создании занятия с флагом `is_recurring` автоматически генерируется серия на 4 недели вперёд
- **Цветовая кодировка:** Цвет события в календаре зависит от цвета выбранного зала
- **Локальное время:** Корректная обработка времени без UTC-сдвигов (диапазон 08:00–20:00)
- **Гибкая система тарифов:** Поддержка групповых, индивидуальных занятий и формата "сплит"
- **Автоматическое списание:** Списание средств за 4 часа до занятия через сервис платежей
- **Умное ценообразование для сплита:** Если в сплит-группу записался один человек — он платит полную стоимость за двоих

#### Система аутентификации и личный кабинет
- **Регистрация и вход:** 
  - Регистрация по номеру телефона (используется как логин)
  - Маска ввода телефона с автоматическим форматированием (+7 (XXX) XXX-XX-XX)
  - Валидация номера телефона
  - Кастомная страница регистрации с современным дизайном (градиентный фон, центрированная форма)
- **Личный кабинет ученика:**
  - Просмотр информации о пользователе
  - История посещений
  - Информация об абонементах
  - Автоматический редирект после регистрации/входа
  - Кастомный дизайн для обычных пользователей (градиентный фон, боковое меню)
- **Ролевая модель:**
  - **Ученик:** просмотр расписания, запись на занятия, отмена записи (не позднее чем за 4 часа до начала); использует кастомные страницы входа и профиля
  - **Модератор:** полный доступ к управлению расписанием (назначается администратором); использует стандартный интерфейс админ-панели
  - **Администратор:** полный доступ ко всем функциям системы, включая назначение модераторов; использует стандартный интерфейс админ-панели
  - **Суперадмин:** полный доступ ко всем функциям системы; использует стандартный интерфейс админ-панели

#### Страницы аутентификации и профиля ✅
- **Кастомная страница входа (`/login/`):**
  - Современный дизайн с градиентным фоном
  - Центрированная форма входа
  - Ссылка на регистрацию
  - Кнопка «Вход для администратора» → перенаправляет на `/admin/login/`
  - Доступна только для обычных пользователей (учеников)
  - Администраторы, модераторы и суперадмины перенаправляются на стандартную страницу входа админ-панели (`/admin/login/`)
- **Кастомная страница профиля (`/profile/`):**
  - Отображение личной информации пользователя
  - История посещений занятий
  - Информация об абонементах и балансе
  - **Динамическое приветствие:** «Доброе утро/день/вечер %имя%» в зависимости от времени суток
  - **Боковое меню:** Отображается только для модераторов, администраторов и суперадминов (использует шаблон админ-панели)
  - Для обычных пользователей — упрощённый интерфейс без бокового меню
  - Доступна для всех ролей, но внешний вид адаптируется под роль пользователя

#### Админ-панель (`core/admin.py`)
- Полное CRUD управление всеми моделями
- Визуальные индикаторы цвета залов в списке
- Кастомные стили через `admin_custom.css`
- Переопределённые шаблоны `base_site.html` и `index.html`
- **Фиксированное боковое меню навигации:** Статичное меню слева для всех страниц админ-панели
  - Вынесено в отдельный шаблон `core/includes/sidebar.html`
  - Скрыто на странице входа (`/admin/login/`) для корректного отображения формы
  - Автоматически скрывает стандартную панель навигации Django
- Управление ролями пользователей (назначение модераторов и администраторов)
- Ссылка на календарь из админ-панели
- Раздел "Core" включает: **Тарифы**, Типы занятий, Пользователи (клиенты), Залы, Занятия, **Записи**, **Финансовые операции**, Посещения, Оплаты, Оплаты аренды, Группы
- Модель `User` наследуется от `AbstractUser` и объединяет функционал пользователя Django и клиента CRM
- Отображение баланса и остатка абонемента в списке пользователей и в карточке пользователя
- Расширенная форма редактирования пользователя с полями: логин, пароль, персональная информация, финансы, **доступные тарифы**, права доступа
- **Управление тарифами:** Создание и редактирование тарифов с автоматическим расчетом цены для сплита
- **Управление записями:** Просмотр всех записей на занятия со статусами и дедлайнами оплаты
- **История операций:** Детальный журнал всех финансовых транзакций с балансом до/после

## 📅 Модуль: Календарь расписания (FullCalendar)

### 🎯 Назначение
Центральный интерфейс для просмотра, создания и управления расписанием занятий йога-студии. Обеспечивает визуализацию занятости залов и управление событиями в реальном времени с учётом ролей пользователей.

### 🛠 Технологический стек
- **Библиотека:** FullCalendar.js v6 (чистый JS)
- **Backend:** Django Views + JSON API
- **Стили:** `calendar.css`
- **Логика:** `calendar.js`
- **Шаблон:** `calendar.html`

### ✨ Ключевые функции

#### 1. Визуализация событий
- **Цветовая кодировка:** Цвет события соответствует цвету зала
- **Формат отображения:** Время, название занятия и зала (например: `10:00 Растяжка | Дом йоги`)
- **Режимы просмотра:** Месяц, Неделя, День, Список
- **Навигация:** Кнопки «Сегодня», «Назад», «Вперед»

#### 2. Управление событиями (CRUD) - только для администраторов и модераторов
- **Создание:** Через модальное окно с выбором типа занятия, зала, времени начала и максимальной вместимости
- **Редактирование:** Двойной клик по событию
- **Drag-and-Drop:** Перетаскивание и изменение длительности
- **Удаление:** С выбором варианта для повторяющихся событий («Удалить только это» или «Удалить это и последующие»)
- **Выбор времени начала:** Два выпадающих списка — часы (08–20) и минуты (00–50 с шагом 10) 
- **Генерация серий:** На 4 недели вперед при повторении
- **Настройка максимальной вместимости:** Ряд из 9 кнопок (от 2 до 10 мест) и поле ввода для произвольного значения, равномерно распределённые по ширине блока в одну строку; визуальная подсветка выбранной кнопки

#### 3. Запись на занятия и посещаемость
- **Модальное окно с вкладками:** При клике на событие открываются вкладки в зависимости от роли пользователя:
  - **Для учеников:** Только вкладка **«Запись»** с заголовком «Запись на занятие»
    - Список уже записанных на занятие учеников
    - Отображение количества свободных мест
    - Кнопка «Записаться на занятие» (при наличии мест и более чем за 4 часа до начала)
    - Кнопка «Отменить запись» (если пользователь записан и более чем за 4 часа до начала)
  - **Для администраторов и модераторов:** Две вкладки:
    - **«Редактирование»:** Изменение параметров занятия (тип, зал, время, описание, максимальная вместимость)
    - **«Запись»:** Управление списком участников
      - Чекбоксы для отметки фактического посещения
      - Ручное добавление клиентов через поиск по имени/телефону
      - Кнопка «Сохранить» для обновления списка посещаемости
      - Учёт посещения для последующего списания средств с баланса

#### 4. Навигация и доступ
- **Кастомное боковое меню:** Доступно на всех страницах календаря и в личном кабинете ученика
- **Ролевой доступ:** Автоматическое перенаправление пользователей в зависимости от роли (ученики → кастомные страницы, персонал → админ-панель)

### 📡 Взаимодействие с Backend

| Действие | Endpoint | Метод | Описание |

## 💰 Система оплаты и списаний

### Архитектура
Система оплаты построена вокруг трех ключевых моделей:
1. **Tariff** — определяет стоимость занятий разных типов
2. **Booking** — фиксирует запись пользователя на занятие
3. **PaymentTransaction** — детализирует каждую финансовую операцию

### Процесс списания средств
1. Пользователь записывается на занятие → создается запись со статусом `confirmed`
2. Автоматически устанавливается дедлайн оплаты (за 4 часа до начала занятия)
3. **Сервис PaymentService.process_payment_deadlines()** проверяет записи с наступившим дедлайном
4. При наступлении дедлайна происходит списание средств с баланса пользователя
5. Создается транзакция с типом `debit` с указанием баланса до и после операции
6. Статус записи меняется на `paid`

### Тарифы
| Тип тарифа | Описание | Ценообразование |
|------------|----------|-----------------|
| **Групповой** | Занятия в группе до 10 человек | Фиксированная цена за человека |
| **Индивидуальный** | Персональная тренировка | Повышенная цена за персональный формат |
| **Сплит** | Занятие для пары (до 2 человек) | Если записались 2 человека — цена делится пополам; если 1 — платит полную стоимость за двоих |

### Команды управления
```bash
# Наполнение базы тестовыми данными (тарифы, пользователи, занятия, записи)
python manage.py seed_data

# Ручной запуск процесса списания (для тестирования)

```

## ⚠️ Известные проблемы
